`devnet.json` is generated by `npm run devnet:keys` (see [scripts/setup-devnet-keys.ts](../scripts/setup-devnet-keys.ts)) and is safe to commit — it only holds public keys and program/mint addresses added by later phases (Phase 1 mints, Phase 6 program IDs).

Secrets (Helius API key, RPC URL) live in `.env` files (see `.env.example` at the root, in `scripts/`, and in `relayer/`) — never in this file.

Devnet keypairs generated for `admin`, `relayer`, `alice`, `bob`, `carol` are written to `.keys/*.json` at the repo root and are gitignored.
